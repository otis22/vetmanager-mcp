# Уроки визуального гейта 341 — 24.09.2026

Гейт 341 принял снимки, которые не покрывали страницу: скриншоты ограничивались первым viewport, поэтому `#examples` и содержимое кабинета под конфигом отсутствовали. Сняли три состояния вместо всех веток из кода. Запросили светлую и тёмную темы, хотя CSS тёмную не реализует; парные PNG совпали побайтно. Промпт просил оценить композицию и не заставлял читать видимые слова: склейки статуса с пунктом были видны, но не отмечены. Opus тогда не получал пиксели; это исправлено этапом 344.

Перед ревью теперь нужен локальный скрипт, который выводит состояния из кода, принимает только реализованные темы, снимает full_page на desktop и phone и отдельно первый экран phone. Он проверяет полный набор и уникальность SHA-256; провал останавливает гейт. Промпт обязан просить прочитать весь видимый текст, проверить смысл и противоречия, дубли, подписи без объекта и элементы вне палитры. Astra получает PNG через `-i`, Opus через `--image`; metadata Opus сверяется с файлами.
