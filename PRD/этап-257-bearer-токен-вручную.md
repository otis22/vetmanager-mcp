# Этап 257. Ясное имя ручного выпуска Bearer-токена

## Цель

Явно сказать в ручном раскрывающемся блоке, что его результат — выпуск
Bearer-токена, а не настройка неизвестного объекта.

## Архитектурное решение

Меняются только две связанные user-facing строки: summary и подсказка быстрого
выпуска. Остальные подписи страницы проверяются вручную; существующие тексты,
которые уже называют результат (ключ, токен, доступ), не переписываются без
пользы. Rollback — возврат двух строк.

Architecture Critique: not required; нет изменения public/API/security contract.

## Декомпозиция

1. Заменить summary и hint, добавить DOM-regression. ≤50 LOC.
2. Полный suite и аудит.

## Acceptance criteria

- Summary: «Выпустить Bearer-токен вручную».
- Hint согласован с этим названием.
- Остальные подписи токенов не описывают механизм вместо результата.
