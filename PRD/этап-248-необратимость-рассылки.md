# Этап 248. Предупреждение о необратимой рассылке

## Цель

Сделать необратимость трёх message write-инструментов явной для MCP-клиента.

## Проверенные факты и декомпозиция

`MessagesController` имеет только POST users/all/roles и GET reports; отмены, удаления и read mark нет. Добавить одинаковое предупреждение в три docstring и schema-тест.

## Архитектурное решение

Это предупреждение в существующем tool contract, без несуществующего confirmation API. Инвариант: все пути отправки сообщают, что отмена/отзыв невозможны. Architecture Critique: required (public write contract).

## Критерии готовности

Все три tool description содержат предупреждение; tests проверяют его.
