# Этап 329. Санитайзер ключей и тумблеров

## Цель

Расширить value-level защиту `get_properties` для распространённых API-токенов
и убрать массовое ложное скрытие русских тумблеров с «Включить»/«Отключить».

## Scope

1. Добавить prefix и long-base64url token patterns из пользовательского списка.
2. Экспортировать единый matcher/константу для real-suite, чтобы не было копии
   oracle.
3. Ограничить русскую морфему `ключ` отрицательными lookbehind.
4. Проверить dump ВМ только по `property_name`/`property_title`, без значений,
   и записать count до/после в AssumptionLog.

## Архитектурное решение

Проблема относится к границе публичного MCP-ответа: matcher обязан применяться
до возврата строки, а real-suite должен проверять ровно ту же production-policy.
Остаётся один pure module `property_privacy.py`; импорт функции в real-suite
исключает рассинхронизацию двух регулярных выражений. Альтернатива — отдельный
test-only oracle — отвергнута: его уже не обновили при расширении распознавания.

Для token ≥32 допустим lower- или uppercase base64url с цифрой; для общего
24-char alnum сохраняется требование mixed case. Эти value patterns применяются
к полному значению, не к подстроке URL/path/hostname. Русский `ключ` допускается
только в начале слова или после некириллического символа
(`(?<![а-яё])ключ` с `IGNORECASE`): это сохраняет «Ключ API» и не скрывает
«Включить», «Отключить», «Подключение» и «Исключить».

Инварианты: имя/заголовок-секрет остаётся замаскированным независимо от value
matcher; pagination не меняется; matcher не логирует и не возвращает входное
значение; real test не печатает raw value. Rollback при непредвиденном
ложном срабатывании — сузить только соответствующее value pattern отдельным
этапом с красным regression-тестом; denylist по имени и placeholder не
отключаются.

## Декомпозиция

1. ≤120 LOC: красные unit-тесты и matcher.
2. ≤80 LOC: name/title regression и dump-count evidence.
3. ≤80 LOC: full checks, review, commit/push/CI.

## Acceptance criteria

- Все пользовательские формы positive tokens представлены только синтетическими
  фикстурами и redacted; `10:00-19:00`, timezone, hostname, e-mail, телефон,
  UUID, API path, version, русское слово и JSON-настройка остаются без изменения.
- `Включить SMS-уведомления` не secret, `Ключ API Idexx` secret.
- Real-suite использует matcher production модуля.
- В тестах, PRD и AssumptionLog нет реальных property values.
