# Этапы 240–241 — качество событий трекинга

## Цель

Вернуть в manual Sentry event полезный текст upstream-ошибки и гарантировать,
что один отказ MCP-инструмента создаёт ровно одно событие.

## Контекст и проверенные факты

- В PYTHON-8 HTTP 406 с текстом `Invalid sort item name: <date_admission>`
  пришёл через automatic path без изменений.
- В PYTHON-9/PYTHON-A тот же контекст через `capture_tool_failure` получил
  `ToolError: [Filtered]`.
- `_sanitize_event` удаляет request/user/contexts/breadcrumbs/extra у manual
  event и дополнительно заменяет каждый `exception.values[*].value` целиком.
  Последнее правило и стирает безопасный upstream text.
- `ToolErrorTrackingMiddleware` помечает внешний `ToolError`, но исходный
  `VetmanagerError` в его явной `__cause__` остаётся без marker. Поэтому
  automatic capture этого domain exception не подавляется, хотя manual capture
  внешнего ToolError уже отправлен.

## Ограничения и приватность

- HTTP MCP transport и контракты интеграций Claude/ChatGPT не меняются.
- Секреты, PII, IP, headers/body/request context и локальные variables не
  отправляются. Clinic domain допустим; `account_id` не PII.
- Меняются только error tracking, его middleware и регрессионные тесты; новых
  runtime-модулей нет, поэтому wheel allowlist не расширяется.
- Production server, DSN и настройки Sentry не затрагиваются.

## Архитектурное решение

Manual event остаётся минимальным: sanitizer сохраняет только allowlisted tags,
stack frames и exception text. Только `capture_tool_failure` ставит transient
opt-in tag для useful upstream text; generic manual/handled events по-прежнему
полностью redact exception value. Opt-in text сохраняет HTTP status, field
names, codes и validation text, а его значения проходят targeted scrub
секретов, labelled PII, email, IP и phone. Секреты продолжают удаляться из
request-like sections и frame locals; transient tag удаляется до отправки в
Sentry и не становится indexed tag.

Marker deduplication расширяется только по явной `__cause__`-цепочке terminal
exception с cycle protection. Это ровно текущий production path (`raise ... from
exc` в tool wrapper), по которому Sentry захватывает исходный `VetmanagerError`;
`__context__` намеренно не трогается, чтобы не подавить несвязанный exception.
Manual event имеет private tag и поэтому никогда не отбрасывается marker-based
filter.

## Acceptance criteria

1. Sanitized manual 406 event содержит `Invalid sort item name: <date_admission>`.
2. Sensitive request data и frame locals остаются redacted; handled connection
   event по-прежнему не раскрывает exception text.
3. Один `ToolError` с `VetmanagerError` в `__cause__` даёт один manual capture;
   subsequent automatic event исходного domain exception returns `None` from
   `_sanitize_event`.
4. Generic manual event без transient opt-in сохраняет full redaction; explicit
   cause is the required wrapper contract and `__context__` is not suppressed.
5. Focused tests, canonical Docker test command, audit, committed Spark and
   Claude reviews, push and green PR completed.

## Out of scope

- Изменение Sentry dashboard/alerts, DSN, production rollout или MCP transport.
- Изменение Sentry grouping или срока жизни marker-а: exception instances
  создаются на конкретный request; existing marker уже имеет этот lifecycle.
