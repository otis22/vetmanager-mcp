# Этап 479. Количества Report AI без ложной маски телефона

## Цель

В первом общем поезде с этапом 480 исправить локальную ложную замену числовых агрегатов количества в строках Report AI при сохранении маскировки настоящих контактных данных. У каждого этапа свой PRD и свои сторожа.

## Evidence и граница

Read-only проверка 19.11.2026 на существующем отчёте исходного подключения #156: прямой ВМ вернул 1097 строк без масок телефона; MCP на тех же строках вернул 104 маски в колонках, обозначающих количество. Исходный job обращения не сохранён, поэтому совпадение с ним не утверждается. Значения и названия колонок в публичный evidence не переносились. Класс локального преобразования подтверждён, бизнес-семантика каждой маскированной ячейки ещё требует типовой проверки.

## План и обязательные сторожа

1. Сопоставить типы колонок и исходные числовые значения на разрешённом контуре, без ПД в фикстурах.
2. Сначала показать красный сторож для агрегата и отдельный красный сторож для маскировки реального телефона; зафиксировать, чем сломан каждый. Затем минимально изменить очистку.
3. Проверить JSON и CSV, все слои деперсонализации, живой изменённый инструмент на стенде и обязательные гейты workflow.

## Вне объёма

В этом документе нет разрешения менять production, запускать новый Report AI job или ослаблять очистку для неразмеченных/контактных колонок. Для живой проверки выбирать разрешённый стенд до запуска; retry существующего `file_id` не создаёт новый job.
